1. Project Overview

InkWeave (墨织) is a structured narrative platform designed for long-form storytelling, fan fiction derivatives, and interactive experimental texts. It offers volume-level management, sandboxed MDX rendering, multi-theme reading engines, and a seamless cross-device experience.

v0.1.0-alpha Next.js 16 + FastAPI Docker Compose

Core Features

Volume & Chapter Tree

3-level hierarchy: Work → Volume → Chapter. Drag-and-drop sorting, batch import/export.

Multi-Theme Engine

4 presets: Light, Midnight, Parchment, Eye Care. CSS Variables, localStorage + cloud sync.

MDX Content Pipeline

Markdown base + HTML/CSS/JS sandbox. Shiki highlighting, collapsible annotations, interactive components.

Tag & Search

Multi-label tagging, Meilisearch full-text with pinyin/typo tolerance, faceted filtering.

Reader Settings

Font size (14-24px), line height, reading progress persistence, offline cache.

Auth & RBAC

JWT auth, roles: author/editor/moderator/admin. Draft/version control.

  • Minimum: 2GB RAM, 20GB disk

Deploy from Scratch


  # 1. Clone repository
  cd /opt
  git clone https://github.com/Vesper36/inkweave.git
  cd inkweave

  # 2. Configure environment
  # .env is pre-configured; edit if needed
  cat .env

  # 3. Start services
  docker compose -p inkweave -f docker-compose.prod.yml up -d

  # 4. Check status
  docker compose -p inkweave -f docker-compose.prod.yml ps
  curl http://127.0.0.1:51638/api/health

  # 5. Verify frontend
  curl http://127.0.0.1:51637/ | head -5

Real-Time Update (Git Webhook)


  # Pull latest code and restart
  cd /opt/inkweave
  git pull origin main
  docker compose -p inkweave -f docker-compose.prod.yml up -d --build

  # Or set up auto-deploy with a cron job:
  # */5 * * * * cd /opt/inkweave && git pull && docker compose -p inkweave -f docker-compose.prod.yml up -d

Nginx Configuration


  # /etc/nginx/sites-enabled/inkweave
  server {
      server_name inkweave.demo.vesper36.cc;

      location /api/ {
          proxy_pass http://127.0.0.1:51638/api/;
          proxy_set_header Host $host;
          proxy_set_header X-Forwarded-Proto $scheme;
      }

      location / {
          proxy_pass http://127.0.0.1:51637;
          proxy_set_header Host $host;
          proxy_http_version 1.1;
          proxy_set_header Upgrade $http_upgrade;
          proxy_set_header Connection "upgrade";
      }

      listen 443 ssl;
      ssl_certificate /etc/letsencrypt/live/inkweave.demo.vesper36.cc/fullchain.pem;
      ssl_certificate_key /etc/letsencrypt/live/inkweave.demo.vesper36.cc/privkey.pem;
  }

5. Data Model

PostgreSQL schema with 6 tables. All primary keys are UUIDv4.


  users
    ├── id (UUID, PK)
    ├── username (VARCHAR 50, UNIQUE)
    ├── email (VARCHAR 255, UNIQUE)
    ├── hashed_password, display_name, avatar_url, bio
    ├── role: 'author' | 'editor' | 'moderator' | 'admin'
    └── timestamps

  works
    ├── id (UUID, PK)
    ├── author_id (FK → users.id)
    ├── title, slug (UNIQUE), description, cover_url
    ├── status: 'draft' | 'reviewing' | 'published' | 'archived'
    ├── word_count, view_count, favorite_count
    ├── content_warning, rating: 'general' | 'teen' | 'mature'
    ├── language
    └── timestamps + published_at

  volumes
    ├── id (UUID, PK)
    ├── work_id (FK → works.id, CASCADE)
    ├── title, description, sort_order
    └── created_at

  chapters
    ├── id (UUID, PK)
    ├── volume_id (FK → volumes.id, CASCADE)
    ├── work_id (FK → works.id, CASCADE)
    ├── title, slug, content (JSONB), content_html (TEXT)
    ├── status, word_count, sort_order, version
    ├── author_note
    └── timestamps + published_at

  tags
    ├── id (UUID, PK)
    ├── name (UNIQUE), slug (UNIQUE)
    ├── color (HEX), category
    ├── usage_count (denormalized)
    └── created_at

  work_tags (M2M association)
    ├── work_id (FK → works.id)
    └── tag_id (FK → tags.id)

6. Development Guide

Local Setup


  # Prerequisites: Node 20+, Python 3.12+, Docker
  git clone https://github.com/Vesper36/inkweave.git
  cd inkweave

  # Backend
  cd backend
  python3 -m venv .venv && source .venv/bin/activate
  pip install -r requirements.txt

  # Frontend
  cd ../frontend
  npm install

  # Start infrastructure (Postgres + Redis + Meilisearch)
  cd ..
  docker compose -p inkweave up -d postgres redis meilisearch

  # Initialize database
  cd backend
  DATABASE_URL="postgresql+asyncpg://inkweave:inkweave_dev_2024@localhost:5432/inkweave" \
    python scripts/init_db.py

  # Start backend (port 8000)
  DATABASE_URL="postgresql+asyncpg://inkweave:inkweave_dev_2024@localhost:5432/inkweave" \
    REDIS_URL="redis://localhost:6379/0" \
    uvicorn app.main:app --reload

  # Start frontend (port 3000)
  cd ../frontend && npm run dev

Database Migrations


  # Generate migration
  cd backend
  alembic revision --autogenerate -m "description"

  # Apply migration
  alembic upgrade head

  # Rollback
  alembic downgrade -1

FAQ

Q: What port does the demo run on?
A: The demo is served via Nginx on HTTPS (443) at inkweave.demo.vesper36.cc. Internal containers use ports 51637 (frontend) and 51638 (backend).

Q: Where is the documentation?
A: inkweave.docs.vesper36.cc (this page) served on internal port 40001.

Q: How to update the demo?
A: cd /opt/inkweave && git pull && docker compose -p inkweave -f docker-compose.prod.yml up -d --build
