1. Project Overview

1. プロジェクト概要

墨织 InkWeave 是一个面向创作者与读者的结构化叙事平台，为长篇连载、同人衍生和互动文本提供卷册管理、沙箱渲染、多主题阅读引擎和全端无缝体验。

InkWeave is a structured narrative platform designed for long-form storytelling, fan fiction, and interactive texts. It offers volume-level management, sandboxed MDX rendering, multi-theme reading engines, and-device experience.

墨織 InkWeave は長編連載、ファンフィクション、インタラクティブテキストのために設計された構造化ナラティブプラットフォームです。巻レベル管理、サンドボックスMDXレンダリング、マルチテーマリーディングエンジンを提供します。

v0.1.0-alpha Next.js 16 + FastAPI Docker Compose

5. 数据模型

5. Data Model

5. データモデル

PostgreSQL 6 张表，主键均为 UUIDv4。

PostgreSQL with 6 tables. All PKs are UUIDv4.

PostgreSQL 6テーブル。全PKはUUIDv4。


  users           → id, username, email, hashed_password, display_name, role
  works           → id, author_id(FK), title, slug, description, status, rating
  volumes         → id, work_id(FK), title, sort_order
  chapters        → id, volume_id(FK), work_id(FK), title, content(JSONB), word_count
  tags            → id, name, slug, color, category, usage_count
  work_tags       → work_id(FK), tag_id(FK)

6. 开发指南

6. Development Guide

6. 開発ガイド


  # Prerequisites: Node 20+, Python 3.12+, Docker
  git clone https://github.com/Vesper36/inkweave.git
  cd inkweave

  # Backend
  cd backend && python3 -m venv .venv && source .venv/bin/activate
  pip install -r requirements.txt

  # Frontend
  cd ../frontend && npm install

  # Infrastructure
  docker compose -p inkweave up -d postgres redis meilisearch

  # Init DB
  cd ../backend
  DATABASE_URL="postgresql+asyncpg://inkweave:inkweave_dev_2024@localhost:5432/inkweave" \
    python scripts/init_db.py

  # Run
  uvicorn app.main:app --reload  # backend :8000
  npm run dev                      # frontend :3000
